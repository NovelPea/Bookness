# Bookness

A mobile-only artwork creator for book covers, game covers, and promotional artwork. Customize the text, style, and colors, add a background photo, preview your design, and download it as a PNG.

## Getting started

1. Copy the complete HTML code into a file named `index.html`.
2. Open the file in a mobile browser.
3. Sign up, choose an artwork tab, customize your design, then tap **Download artwork as PNG**.

No installations or build tools are required.

## Features

- Book cover, game cover, and promotional artwork tabs
- Live artwork preview
- Editable text, styles, and colors
- Optional background photo upload
- PNG downloads
- Demo login and sign-up stored in your browser

## Important

The login is for demonstration only. Account details are stored in browser `localStorage`, so this is **not secure authentication** and accounts aren’t shared across devices. Use a proper authentication service before deploying publicly.

The page is designed for mobile screens and displays a notice on wider screens.
